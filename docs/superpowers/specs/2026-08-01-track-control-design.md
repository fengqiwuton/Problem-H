# 大底盘四驱小车循迹控制优化设计

## 背景

小车底盘约 30 cm x 25 cm，四轮驱动，轮径约 48 mm。八路串口循迹传感器安装在前轮轴前方约 7-10 cm。当前速度下完成一圈约需 18 s，比赛要求控制在 20 s 内。终点为宽黑线，现有程序以至少 4 路传感器同时检测到黑色作为停车条件。

当前主要现象：

- 直线进入弯道时响应偏慢，直到外侧传感器检测到黑线才猛烈转向。
- 曲线转向生硬，出弯时车身斜着进入直线。
- 出弯后的大幅反向调整不断放大，最终可能丢线。
- 终点触发后仅发送零速度，实际停车距离偏长。

## 根因

现有 `user/track_control.c` 中存在以下直接原因：

1. 默认 `Kd` 为 0，无法利用误差变化趋势提前入弯或在出弯时提供阻尼。
2. 居中附近额外叠加固定幅度的周期性左右摆动，主动制造了直线扰动。
3. PD 输出先限制为 60，随后又按误差强制提升到 120、200 或 245，转向指令不连续。
4. 大误差时基础速度只从 200 降到约 150，转向能力不足时只能依赖突然增大的差速。
5. 丢线后最多约 1.2 s 保持左右轮同速前进，弯道丢线时会继续驶离黑线。
6. 主程序在宽线触发后立即发送零速度，没有主动抵消车辆惯性。
7. 控制循环固定为 10 ms，但循迹数字帧异步到达；重复使用同一帧会使微分量与真实采样周期不一致。

## 目标

- 小误差时直线稳定，不主动摆动。
- 在黑线由中心向相邻探头移动时开始入弯，不等待最外侧探头。
- 出弯时转向连续衰减，并在越过中心前提供适量反向阻尼。
- 正常循迹不允许一次指令从小转向直接跳到极限转向。
- 丢线后优先沿最后已知弯道方向找回黑线。
- 终点停车更快，同时避免普通弯道多探头触线造成误停车。
- 保持整圈时间小于 20 s；以当前 18 s 为基准，弯道减速仅短时启用。

## 非目标

- 本次不启用 MPU6050 或磁力计参与循迹。
- 本次不切换到八路模拟量位置计算，保留后续标定升级空间。
- 本次不修改串口接线、循迹模块协议和电机驱动板硬件。
- 本次不加入积分项，避免低速四驱底盘产生积分累积和反向过冲。

## 模块边界

新增纯控制计算模块 `user/track_controller.c/.h`，负责：

- 根据八路黑线位图计算连续位置误差。
- 只在新的数字帧到达时更新误差、微分量和控制状态。
- 输出目标基础速度、转向量以及丢线恢复状态。
- 识别跨越左右区域的宽黑线终点模式。

保留 `user/track_control.c` 负责：

- UART 协议接收与数字帧计数。
- 调用纯控制模块。
- 左右轮速度映射、机械偏差补偿和速度斜坡。
- 执行终点主动制动。

`user/main.c` 负责运行/停止流程、20 s 超时和 OLED 状态显示，不再直接用 `active_count >= 4` 判断终点。

## 控制数据流

每收到一帧新的 `$D...#` 数据后执行一次：

1. 将协议中的 `0` 转换为检测到黑线的位图。
2. 使用连续、左右对称的权重计算位置误差。
3. 更新经过轻度滤波和限幅的误差变化量。
4. 根据误差大小、变化趋势和弯道状态计算连续 PD 转向量。
5. 对转向量施加统一限幅和变化率限制。
6. 根据误差和变化趋势选择目标基础速度。
7. 将基础速度与转向量转换为左右轮目标速度。
8. 对电机目标速度执行非对称斜坡：减速快、加速稍慢。

没有新数字帧时保持上一组目标速度，不重复更新微分项。

## 位置误差与 PD

初始传感器权重使用平滑对称分布：

`{-160, -105, -55, -18, 18, 55, 105, 160}`

多路传感器同时检测到普通黑线时取权重平均值。普通循迹不再根据探头数量强制把误差改成 200 或 330。

初始参数：

- `Kp = 0.75`
- `Kd = 0.55`
- 原始误差差分限制在 `[-80, 80]`，微分滤波使用 `d = (2 * last_d + delta) / 3`，防止数字探头切换产生单帧尖峰。
- 转向统一限幅：初始值 140。
- 转向上升步长：每个新数字帧最多增加 18。
- 转向减小步长：每个新数字帧最多减小 24。目标方向改变时，本帧只能向零点移动且不能跨过零点，后续帧再按每帧 18 增加反方向转向。

中心附近允许小幅连续修正，但不再叠加周期性摆动。参数集中定义，保留现场按 5-10 的步长逐项调整。

## 弯道识别与速度调度

弯道状态带迟滞，防止直线和弯道模式频繁切换：

- 连续 2 帧满足 `|error| >= 45`，或滤波微分与误差同号且 `|d| >= 35` 时进入弯道。
- 连续 6 帧满足 `|error| <= 28` 且 `|d| <= 12` 后退出弯道。
- 退出弯道后的 100 ms 内限制加速速度，使车身先稳定对齐。

初始速度表：

| 条件 | 目标基础速度 |
| --- | ---: |
| 居中直线 | 210 |
| 刚进入弯道或误差快速增长 | 190 |
| `45 <= |error| < 105` | 180 |
| `105 <= |error| < 145` | 165 |
| `|error| >= 145` | 145 |

目标速度降低时每帧最多下降 30，提高时每帧最多增加 8。短时快速降速保证入弯能力，缓慢提速避免出弯再次扰动车身。直线速度略高于当前 200，用于补偿弯道短时减速。

## 丢线恢复

丢线恢复保留最后可靠的误差方向：

- 丢线前 120 ms：以 90 的基础速度保持最后转向方向，避免在弯道中直冲。
- 仍未找回：进入低速定向搜索，内侧轮允许小幅反转，外侧轮保持低速前进。
- 中间两路连续 2 帧重新检测到黑线后退出恢复，转向从当前值平滑回到正常 PD。
- 连续 600 ms 未找回黑线则停车。

## 终点识别与主动制动

终点模式必须同时满足：

- 至少 4 路检测到黑色。
- 左半区和右半区都存在黑色。
- 最左和最右黑色探头的编号差至少为 5，排除普通弯道上 4 个相邻探头同时触线的情况。
- 连续 2 个新的数字帧确认。

确认终点后进入非阻塞制动状态：

1. 保存停车前左右轮实际指令。
2. 发送方向相反、幅度受限的制动指令，持续 40 ms。每侧逻辑制动力取停车前速度的三分之一，绝对值限制为 20-70；停车前该侧速度绝对值小于 30 时直接置零。
3. 随后发送四轮零速度并清除速度斜坡状态。
4. 按键停车和 20 s 超时也复用同一制动流程。

反向制动力和持续时间必须作为独立常量，初始采用较保守数值，避免轮胎反转或电机驱动过流。

## 显示与调参

OLED 保留误差、转向量、传感器位图和丢线计数，并增加当前控制阶段：直线、弯道、恢复、制动。运行时显示的 Kp/Kd 必须与实际控制参数一致。

现场调参顺序固定为：

1. 保持 Kd 不变，只调 Kp，使直线能够回中且不过度摆动。
2. 保持 Kp 不变，只调 Kd，减小出弯过冲。
3. 调整转向变化率，消除转向生硬感。
4. 最后调整速度表和主动制动时间。

每次只改变一个参数，并把结果追加到 `pid_tuning_log.md`。

## 验证

纯控制模块先用确定的传感器序列进行测试：

- 中心线序列不会产生周期性左右摆动。
- 误差逐渐增大时，转向量连续增加且不超过统一上限。
- 误差回到中心并越过中心时，微分阻尼提前减小原转向，不发生单帧反打。
- 相邻探头切换不会造成超过变化率限制的转向跳变。
- 丢线后保持最后方向，找回中心后平滑恢复。
- 普通弯道的相邻多探头模式不判定终点。
- 跨越左右区域的宽黑线连续 2 帧后判定终点。

工程验证分三步：

1. 完整重编译 Keil 工程，确认无新增错误和警告。
2. 架空四轮检查左右轮方向、差速方向和主动制动方向。
3. 实车依次测试直线、单弯、连续弯和完整一圈，记录圈速、最大误差、是否丢线及停车距离。

验收标准：完整一圈不丢线、不出现连续放大的左右摆动，出弯后不等待最外侧传感器才反向修正，圈速小于 20 s，终点停车距离明显短于当前版本。
